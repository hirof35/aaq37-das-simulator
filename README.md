# AN/AAQ-37 EO-DAS Simulator

F-35戦闘機に搭載されている全方位赤外線センサーシステム**「AN/AAQ-37 EO-DAS（Distributed Aperture System：分散開口システム）」**を模した、Node.jsベースのリアルタイム・テレメトリ・シミュレーターです。

機体周囲6箇所に配置された赤外線カメラ（アパーチャ）が、接近する脅威（ミサイルや敵航空機）をパッシブ探知し、WebSocketを通じてブラウザの監視画面（HMD風UI）へリアルタイムにストリーミングする仕組みを再現しています。

## 🚀 機能特徴

- **6軸全球パッシブ探知シミュレーション**: 前方上下、左右、後方上下の6つの独立したセンサー視野（FOV）を再現。
- **リアルタイム・データ・ストリーミング**: `ws` (WebSocket) を使用し、バックエンドからフロントエンドへ1秒未満の低遅延でデータを同期。
- **動的脅威ジェネレーター**: バックエンドでランダムに発生した脅威（SAM、AAM、航空機）が、マッハ数に応じた速度で自機へ接近する挙動をシミュレート。
- **アビオニクス風UI**: 軍用機のコックピットやHMD（ヘルメットマウントディスプレイ）をイメージした、グリーン基調のレスポンシブな監視画面。

## 🛠 動作環境

- Node.js (v14以上推奨)
- npm (Node.jsに同梱)
